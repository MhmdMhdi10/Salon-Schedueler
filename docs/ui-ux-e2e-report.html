اصلاحات مهم انجام‌شده

موبایل و navigation

  • نوبار مالک از ارتفاع ۵۶ به ۶۴ پیکسل رسید.
  • آیکن‌ها ۲۴ پیکسل و فاصله‌ی متن/آیکن gap-2.5 شد؛ ناحیه‌ی لمس مناسب‌تر شد.
  • درصد و overflow افقی روی routeهای عمومی، funnel و پنل مالک اندازه‌گیری شد.

ورود و نقش‌ها

  • کاربر عادی بعد از ورود به /account می‌رود و landing برای session لاگین‌شده قفل است.
  • کاربر بدون role اگر مستقیم وارد /owner/* شود به حساب مشتری برمی‌گردد.
  • Owner/Admin/Stylist هم در UI guard و هم در API authorization پوشش داده شدند.

تقویم و دسترسی

  • برنامه‌ی کاری هفتگی صفحه‌ی مستقل با back navigation دارد.
  • ساختار ARIA نمای هفته/ماه اصلاح شد؛ gridcellها داخل row معتبر هستند.
  • غیرفعال‌سازی آرایشگر دیگر فقط حذف local نیست؛ با PATCH واقعی ذخیره و در خطا rollback می‌شود.

خطا و build quality

  • ErrorState عنوان semantic از نوع h2 و همچنان role=alert دارد.
  • QR malformed/unregistered از هم تفکیک شدند؛ gate اشتراک QR نیز تست شد.
  • قرارداد bundle با routeهای واقعی هماهنگ شد؛ public initial JS در سقف ۲۴۰KB gzip باقی ماند.
  • بیعانه از تنظیمات سرویس قابل تعریف شد؛ پرداخت فقط برای مشتری صاحب همان رزرو ساخته می‌شود.
  • مسیرهای مستقیم staff و حذف سرویس، tenant scope و بررسی مالکیت resource دارند.
