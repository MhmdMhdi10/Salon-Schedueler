۱. وضعیت فعلی — آیا پروژه برای MVP آماده است؟

بله — با شرایط

پروژه از نظر معماری، اسکیما، سرویس‌های دامنه، و فرانت‌اند بسیار بالغ‌تر از سطح MVP است. اما چند مورد عملیاتی (دیپلوی، متغیرهای محیطی، تست یکپارچه‌سازی واقعی پرداخت) باید قبل از انتشار عمومی رفع شوند.

نقاط قوت کلیدی

  • اسکیمای دیتابیس: ۳۰ مدل، کاملاً پوشش‌دهنده سالن/نوبت/پرداخت/اشتراک/بات — فراتر از MVP
  • بک‌اند: ۱۷+ سرویس دامنه، ۱۶ فایل روت، میان‌افزار RBAC/Rate-limit/Auth، موتور زمان‌بندی ۵۳KB با تست property-based
  • فرانت‌اند: ۲۵+ صفحه پیاده‌شده، ۴۵+ کامپوننت، سیستم توکن کامل، PWA آماده، i18n فارسی ۹۲KB
  • تست: ۵۰+ فایل تست (unit + property + integration + e2e + a11y)
  • زیرساخت: Docker Compose (dev + prod)، CI/CD، Nginx، اسکریپت backup
  • بازار ایران: تقویم جلالی، ارقام فارسی، درگاه زرین‌پال/آیدی‌پی، پیامک کاوه‌نگار/SMS.ir، بات تلگرام+بله

نقاط ضعف بحرانی (مانع انتشار)

  • بحرانی theme_color در manifest.json هنوز #2456D8 (نیلی قدیمی) — باید #0B7A68 شود
  • بحرانی تست یکپارچه‌سازی واقعی درگاه پرداخت (Zarinpal sandbox) اجرا نشده
  • بحرانی هیچ rate-limit سراسری روی auth/OTP در production وجود ندارد (فقط فایل وجود دارد — باید تأیید شود فعال است)
  • مهم فایل .env.example بک‌اند ۳۰+ متغیر دارد — مستندات دیپلوی ناکافی
  • مهم صفحات Discovery/Search ساخته شده ولی غیرفعال — redirected to /

۴. موارد اضافه‌شدنی — چه چیزهایی کم است

ضروری برای MVP (باید باشد)

  • P0 صفحه ثبت‌نام سالن (Onboarding): فرم wizard برای صاحب سالن جدید — وجود دارد ✓ (/business/register با ۴۳KB)
  • P0 درگاه پرداخت عملیاتی: Zarinpal sandbox تست‌شده — کد وجود دارد، تأیید عملیاتی لازم
  • P0 ارسال واقعی پیامک OTP: adapter کاوه‌نگار + SMS.ir وجود دارد — تست واقعی لازم

بسیار مهم (هفته اول بعد از لانچ)

  • P1 مدل Review/Rating: برای اعتمادسازی مشتری — در اسکیما نیست
  • P1 گالری تصاویر سالن: مدل Image/Media — نمونه‌کار برای جذب مشتری حیاتی
  • P1 آدرس و مختصات جغرافیایی سالن: برای نقشه و SEO محلی
  • P1 دسته‌بندی خدمات: وقتی سالن ۲۰+ خدمت دارد، UX بدون دسته‌بندی ضعیف می‌شود
  • P1 Terms of Service + Privacy Policy محتوا: صفحات وجود دارند اما محتوا باید حقوقی و واقعی باشد

مهم (ماه اول)

  • P2 سیستم کد تخفیف/کوپن: برای کمپین‌های بازاریابی
  • P2 نوبت‌دهی چندخدمته: مشتری بتواند در یک رزرو چند خدمت انتخاب کند
  • P2 یادآوری خودکار (Push): cron وجود دارد اما push notification واقعی تست نشده
  • P2 Error tracking (Sentry): برای تشخیص سریع مشکلات production
  • P2 Analytics واقعی (GA4 یا جایگزین ایرانی): ردیابی فانل رزرو

۷. استراتژی مارکتینگ — عملی و مقرون‌به‌صرفه

فاز ۱: لانچ (ماه ۱–۲) — بودجه: ۵–۱۰ میلیون تومان

کانالاقدامهزینه تخمینی
🎯 فروش مستقیممراجعه حضوری به ۱۰۰ سالن تهران، نصب QR رایگان + آموزش ۱۵ دقیقه‌ایهزینه چاپ QR + حمل‌ونقل
📱 اینستاگرامصفحه اختصاصی + ریلز آموزشی (نحوه رزرو از دید مشتری)تولید محتوا ~۳M/ماه
💬 تلگرام/بلهگروه‌های صنفی آرایشگران — معرفی + دمو رایگانرایگان
🤝 Referralهر سالن معرف = ۱ ماه رایگانهزینه فرصت

فاز ۲: رشد (ماه ۳–۶) — بودجه: ۱۵–۲۵ میلیون/ماه

  • اینفلوئنسر مارکتینگ: میکرو اینفلوئنسرهای حوزه زیبایی (۱۰–۵۰K فالوور) — هر کدام ~۲–۵M
  • تبلیغات یکتانت/تپسل: تارگت جغرافیایی (تهران → شهرستان‌ها)
  • SEO: فعال‌سازی صفحات Discovery بعد از ۵۰+ سالن — سئوی محلی
  • محتوای آموزشی: بلاگ + ویدیو (نکات مدیریت سالن، جذب مشتری)
  • همکاری با تأمین‌کنندگان: برندهای لوازم آرایشی = کانال معرفی به سالن‌ها

فاز ۳: تثبیت (ماه ۶–۱۲)

  • برنامه وفاداری: سیستم تخفیف برای مشتریان وفادار هر سالن
  • Marketplace: فعال‌سازی صفحه جستجو — مشتری سالن پیدا می‌کند
  • اپ موبایل: لانچ نسخه React Native (push + offline)
  • B2B: پنل مدیریت زنجیره‌ای برای برندهای چند شعبه‌ای

تاکتیک‌های کم‌هزینه (همیشه فعال)

  • 🏷️ QR فیزیکی رایگان: چاپ و نصب QR در سالن = بهترین کانال ارگانیک
  • ⭐ نمونه‌کار اینستاگرام: هر رزرو = فرصت محتوا (before/after)
  • 🔔 یادآوری خودکار: پیامک/بات = retention بالا + کاهش no-show
  • 📊 گزارش ماهانه رایگان: به صاحب سالن = ارزش perceived بالا
  • 🗣️ Word of mouth: تجربه خوب مشتری = بهترین تبلیغ (UX عالی = رشد ارگانیک)

خلاصه نهایی

پروژه آرا از نظر فنی در سطح بسیار بالایی قرار دارد — معماری تمیز، تست‌های گسترده، UI/UX حرفه‌ای فارسی، و اینتگریشن‌های بازار ایران. با ~۱۰ ساعت کار عملیاتی (تست درگاه واقعی + SSL + مستندات دیپلوی) آماده انتشار MVP است.

بزرگ‌ترین ریسک فنی: عدم تست واقعی پرداخت و پیامک.
بزرگ‌ترین ریسک بیزینسی: جذب اولیه سالن‌ها (chicken-and-egg problem) — حل: فروش مستقیم + trial رایگان.
