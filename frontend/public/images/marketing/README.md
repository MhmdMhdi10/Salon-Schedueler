# Marketing / Feature Section Images

Development SVG placeholders for marketing feature sections on the landing page
and other promotional surfaces.

## For Production

Replace each SVG with real photography matching the NYC editorial direction.

| Width | Format | Aspect Ratio | Usage |
|-------|--------|--------------|-------|
| 960w | AVIF | 4:3 (960×720) | Feature section images |
| 640w | AVIF | 4:3 (640×480) | Mobile feature images |
| 960w | WebP | 4:3 (960×720) | Fallback |

## Photography Direction

These images support the "How It Works" and feature showcase sections:

- **Discover:** Customer browsing salons on phone, or a curated salon grid/collage
- **Book:** Hand tapping a booking button, or time-slot selection on screen
- **Results:** Styled hair/nails/beauty result, editorial quality

All should maintain the NYC editorial aesthetic with dramatic lighting and warm tones.
